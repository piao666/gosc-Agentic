# Research Task Brief · T1 验收归档

- 本轮核对 T1 的运行记录能否从无模型合同、失败和恢复一路追溯到最终合成现场验收。研究证据沿用各次 HPC 登记。
- 范围包括 T1 Driver、测试与审计、隔离的合成计划、存储和恢复记录、全量登记索引、可公开的小型证据副本、总报告和一次普通 GitHub 提交。工作区的独立审阅附件保留在本地。
- 验收为逐份核实运行身份、状态、产物 SHA 和回传凭证，检查当前代码和提交范围，复核一次正常推送后的远端引用。未知字段保留，失败保留，已有证据不重新归属。
- 本轮成本为本地文件、哈希与 Git 管理，以及远端只读引用与记录核对。没有新增模型请求、测试或科研计算。新场景、T2 调整和真实 B1 属于后续各自的研究关卡。
