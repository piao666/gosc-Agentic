# B04 Adaptable Semantic Compression 精读记录

- 范围：14页PDF中p.1、3–4模型/目标，p.6–9 importance/拟合/CRRA/CRRAUS，p.10设置与p.13结论；视觉核验p.7 Algorithm1/2。未独立重证AppendixA、所有SCA不等式或所有曲线。
- [PAPER] Chuanhong Liu、Caili Guo、Yang Yang、Nan Jiang；题名 Adaptable Semantic Compression and Resource Allocation for Task-Oriented Communications，arXiv:2204.08910v1。本地快照不替代出版主页核验。
- [PAPER] p.3–4 Eq.(1)–(14)：多用户上行至edge，semantic feature提取/重要性裁剪/编码，带宽Bi、功率Pi决定Shannon-rate和时限内成功概率；任务成功Φi=η(oi)P(ti≤t0)。联合优化压缩oi、带宽/功率和二元user selection，预算及最低服务约束，SLA权重不是在线receiver-private-state估计。
- [PAPER] p.6 Eq.(19)：对task concept输出相对于feature map的梯度全局平均形成重要性；按重要性阈值删特征。重要性当作两端共享KB、无需额外发送索引，是特定共享知识假设，不能直接套在异构动态LLM memory。
- [PAPER] p.6–7 Eq.(20)及Algorithm1：压缩率–任务成功曲线η(o)由离线评价点拟合指数函数；不是已知真实闭环任务价值函数。部署模型/任务改变需重新验证拟合与知识一致性。
- [PAPER] p.7–8 Algorithm2–4：固定资源逐用户0.01步长枚举压缩；固定压缩以SCA/松弛变量处理资源非凸性，交替至收敛。p.9 Lemma2给相应条件下资源子问题KKT结论；不是原混合整数联合问题全局最优定理。
- [PAPER] p.9 Algorithm5/6：异质SLA加branch-and-bound user selection，与压缩/资源交替；较高计算复杂度换服务优先级。已知数学结构是混合离散连续、代理性能曲线、分块优化、SCA和分支界定，而非新的“语义通信联合优化”空白。
- [PAPER] p.10 Sec.VI：10用户edge，STL-10图像分类，VGG/ResNet，FCR固定压缩、FRA固定资源、MSR sum-rate及传统JPEG。主要为分类成功率/加权成功概率和资源，不是开放式LLM多Agent协作；不把摘要80%压缩当本项目实测。
- [PAPER] p.13作者展望统一importance和更低求解复杂度。[HYPOTHESIS] 第一篇先固定GOSC传输与调度，只研究低成本value，否则压缩/encoder/solver一起改变不可归因；第二篇再考虑联合设计也必须区别于此文及GOSC。
